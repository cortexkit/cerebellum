# Fork-tool call vectors

Source: the agent-runner (thalamus) repository's published `fork-tools-v1`
samples, recorded from its real-host `runner/fork/` tests and kept there under
`crates/thalamus-harness-module/test-vectors/fork-tools-v1/` (`SHA256SUMS`
SHA-256: `e3125ad2aa6c4484dfa91e1f6a1e60615b585a835ab8a10dfcc60d3a2709bc6e`).

The three host files and `SHA256SUMS` are byte-for-byte upstream copies. Each
replay uses the `tool.call.request` object from its host file.
